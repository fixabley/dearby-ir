# Dearby 학교·프로젝트 발표자료

기준일: 2026-09-22. 본문 12장과 질의응답용 부록 3장으로 구성했습니다. 본문 권장 시간은 약 7분입니다. 제품 방향과 핵심 탐색 흐름은 합의했지만 세부 명세 및 새 추천 기능 구현은 미완료입니다.

## 파일

- `dearby-school-presentation-final.pptx`: 텍스트·표를 편집할 수 있는 발표자료. 슬라이드별 발표자 노트 포함.
- `dearby-presentation.md`: 슬라이드 내용, 발표 대본, 상태와 근거 문서를 담은 수정용 원고.
- `dearby-presentation.json`: 슬라이드별 제목·내용·대본·디자인 설정을 담은 구조화 원본.
- `assets/collaboration-concept.png`: 표지에 사용한 AI 생성 콘셉트 이미지. 실제 행사·이용자 사진이 아닙니다.

## 수정 방법

문장과 기획 내용을 고치려면 Markdown을, 슬라이드별 데이터를 일괄 수정하려면 JSON을 사용하세요. 두 파일과 PPTX는 자동 동기화되지 않습니다. 수정 후 다시 생성할 때 어떤 파일이 최신인지 지정하면 됩니다.

JSON의 `slides` 배열이 슬라이드 순서이며 `title`은 제목, `notes`는 발표자 원고, `status`는 합의·제안·미정 구분, `sources`는 근거 문서입니다. `columns`, `steps`, `items`, `headers`/`rows`는 해당 슬라이드의 본문입니다. `seconds`는 권장 발표 시간이며 효과 측정 데이터가 아닙니다.

PPTX의 텍스트·표는 직접 수정할 수 있습니다. 글꼴은 Apple SD Gothic Neo입니다. 해당 글꼴이 없는 발표 기기에서는 사용 가능한 한글 글꼴로 일괄 변경하고 줄바꿈을 확인하세요.

## 발표 범위

본문 1~12장만 발표하고 부록은 질의응답에 사용하세요. 결과 수 12개는 가상 예시입니다. 자동 수집·개인화 추천·운영 태그 검토는 새 기획이며 구현 완료로 설명하지 않습니다. ELK 및 PostgreSQL의 최종 구성, 추천 가중치, 수집 운영 기준, 정량 성공 목표는 미정입니다.

## 디자인

사용자가 요청한 design-taste-frontend의 관련 원칙을 발표자료에 적용했습니다. 2026-09-22 후속 수정에서 1440×810(16:9) 발표 캔버스로 재구성했습니다. 초록 브랜드색을 유지하며 표지·문제 정의·결론에는 짙은 초록 배경을, 설명 장에는 밝은 배경을 사용합니다. 프로그램 관계, 추천 순서, 선택 흐름과 구현 상태를 서로 다른 구성으로 표현합니다. 화면에 맞춰 캔버스가 축소되며, 700px 미만에서는 읽기 좋은 세로 구성으로 전환합니다. 디자인 변화 6, 모션 2, 정보 밀도 3이며 모션 축소 설정을 존중합니다.

## HTML 발표자료

`dearby-presentation.html`은 이미지와 스크립트가 포함된 단일 파일입니다. 더블클릭해 브라우저에서 열 수 있고 외부 서버·CDN이 필요하지 않습니다. 방향키로 이동, N으로 원고 표시, F로 전체화면을 전환합니다. 상단 목록으로 부록을 포함한 15장 중 원하는 장을 선택할 수 있습니다. 인쇄/PDF에서는 전체 슬라이드를 출력하도록 구성했습니다.

JSON 수정 후 아래 명령으로 HTML을 다시 생성할 수 있습니다. Python 표준 라이브러리만 필요합니다.

```sh
python3 build_html.py
```

`build_html.py`, `presentation-template.html`, `presentation.css`, JSON, assets 폴더는 같은 디렉터리 구조를 유지하세요. `display_heading`은 화면용 요약 제목이며 대본과 기획 상태는 그대로 유지합니다. 스타일은 CSS, 공통 조작 기능은 HTML 템플릿에서 수정합니다. HTML을 직접 수정하면 재생성 시 덮어써지므로 내용은 JSON에서 수정하는 편이 좋습니다. MD와 PPTX는 이 명령으로 갱신되지 않습니다. 이번 디자인 수정은 HTML에 적용했으며 PPTX는 이전 디자인입니다.

GitHub Pages는 저장소 루트 `index.html`을 제공합니다. 재생성한 HTML을 루트 `index.html`에 복사한 뒤 게시합니다. 원고와 개인 메모 등 발표 외 인계 문서는 게시 대상으로 추가하지 않습니다.

## 초기 수집 제안과 발표 순서

문제 → 대상·제공 가치 → 수집 범위(4번) → 수집 방법(5번) → 맞춤 기준·태그(6번) 순서입니다. 수집을 2장으로 확대하고 기존 맞춤 기준·태그 2장을 1장으로 통합했습니다. 본문 12장과 부록 3장은 유지하며 권장 발표 시간 합계는 440초입니다.

초기 범위는 컨퍼런스·연합동아리·교육 및 육성 프로그램입니다. 구글로 출처를 발견하고, 등록한 공식 원문을 수집·검토하는 방식을 제안합니다. 구현 완료 또는 운영 정책 확정이 아닙니다. 상세 근거는 `collection-proposal-2026-09-22.md`에 있습니다. JSON·Markdown·HTML을 함께 수정했고 PPTX는 갱신하지 않았습니다. 태그는 대표 예시만 화면에 남기고 세부 설명은 원고에 보존합니다.
